Document editor browser dependencies

TipTap and its reached browser dependencies are packaged with this editor.
The @bosca/bml runtime is supplied by the consuming application.
Embedded code blocks also bundle the CodeMirror packages and language engines
listed, with their MIT notices, in source-view.txt in this directory.
