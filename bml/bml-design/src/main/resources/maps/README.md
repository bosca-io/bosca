# Shared world map boundaries

`world.geojson` comes from Natural Earth’s 1:110m Admin 0 Countries dataset:
https://www.naturalearthdata.com/downloads/110m-cultural-vectors/110m-admin-0-countries/

Natural Earth data is public domain:
https://www.naturalearthdata.com/about/terms-of-use/

This copy omits Antarctica, retains only the region name and geometry, and rounds
coordinates to three decimal places. The catalog supplies its own illustrative values; applications supply their own data.
Boundaries are bundled with the Design Library; browsers do not download external map data.
