# Catalog map boundaries

`world.geojson` comes from Natural Earth’s 1:110m Admin 0 Countries dataset:
https://www.naturalearthdata.com/downloads/110m-cultural-vectors/110m-admin-0-countries/

Natural Earth data is public domain:
https://www.naturalearthdata.com/about/terms-of-use/

The catalog copy omits Antarctica, retains only the region name and geometry, and rounds
coordinates to three decimal places. Values displayed in the catalog are illustrative.
Boundaries are bundled with the catalog; browsers do not download external map data.
