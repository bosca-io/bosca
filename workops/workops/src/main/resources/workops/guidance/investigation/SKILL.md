# Investigation

Read the current code, contracts, related documents, tests, and runtime evidence. Identify the owning module, existing vocabulary, authorization boundaries, and dependencies. Separate observations from assumptions and record unresolved questions.

Use read-only operations until the scope is understood. Keep the WorkOps item current with evidence, affected files, risks, and the next useful investigation. Confirm the MCP target before creating or changing records. Reuse Bosca's services and infrastructure abstractions.
