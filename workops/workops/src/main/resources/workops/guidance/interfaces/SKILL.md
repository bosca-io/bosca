# Interface review

Begin implementation by writing interfaces, models, method signatures, API shapes, and representative callers. Show how a user or consumer will use them. Keep the first iteration focused on contracts and usage, then iterate on names, responsibilities, and failure behavior before building the full implementation.

Record concrete declarations and file paths with workops_plan review_interfaces and a substantive review note. A review records the caller's assessment; the tool does not inspect source files or execute code. Revisit the interfaces and review if contracts, requirements, guidance, or scope change. Consult the effective typed policy for enforced gates.
